# 👾 Alien Invasion

Учебная игра на Python и Pygame: космический корабль против флота пришельцев. В коде реализованы перемещение корабля, выстрелы, движение пришельцев и столкновения.

## Запуск

Для проекта нужен Python и библиотека Pygame:

```bash
python3 -m pip install pygame
python3 alien_invasion.py
```

Игра находится в разработке: текущая версия содержит ошибку при запуске, поэтому указанные команды пока могут завершиться ошибкой.

## Управление

- Стрелки влево и вправо — движение корабля.
- Пробел — выстрел.
- Q — выход.
